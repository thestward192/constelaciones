# Constelaciones

Reto de 365 días donde la comunidad construye un universo, estrella por estrella.

- Requisitos: Node.js 22.12 o más reciente.
- Instalar: `npm install`
- Ver en local: `npm run dev` y abrir http://localhost:3000
- Pruebas: `npm test` y `npm run test:e2e`

Documentación en [docs/](docs/) y estado en [PROGRESO.md](PROGRESO.md).
